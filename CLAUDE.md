## Project Overview

7z快捷压缩 — a macOS-native file compression desktop app built with Python + embedded HTTP server + browser-based UI. It wraps `p7zip` (7z) behind a local web GUI so users can drag-and-drop files to compress.

## Architecture

The app is a single Python process that:

1. **`launcher.py`** — Entry point. Starts an HTTP server on `127.0.0.1:8765`, serves the HTML UI, and opens it in the default browser. All compression logic runs server-side via subprocess calls to the `7z` binary. API endpoints are POST routes:
   - `/check_7z` — locate the 7z binary (bundled → homebrew → PATH)
   - `/stat` — check if a file path exists
   - `/compress` — run `7z a` with user-specified options (format, level, password, split volumes)
   - `/pick_files`, `/pick_folder` — macOS native dialogs via `osascript`
   - `/open_finder` — reveal output in Finder via `open -R`

2. **`html/index.html`** — Single-page UI with drag-and-drop zone, file list, compression options (7z/zip, level 0-9, password, split volumes, output dir). Communicates with the Python backend via `fetch()` calls.

3. **`build_app.sh`** — Builds a macOS `.app` bundle and `.dmg` installer using PyInstaller. Copies `p7zip` binaries into the app bundle's Resources.

4. **`7z快捷压缩.spec`** — PyInstaller spec file (also auto-generated by `build_app.sh`).

## Build & Run

```bash
# Run directly (requires 7z installed: brew install p7zip)
python3 7z_tool/launcher.py

# Build macOS .app bundle and .dmg
cd 7z_tool && bash build_app.sh
```

## Key Details

- **7z binary discovery order**: bundled `p7zip/7z` inside the .app → `/opt/homebrew/bin/7z` → `/usr/local/bin/7z` → `shutil.which("7z")`
- The spec file and `build_app.sh` both define the PyInstaller config; `build_app.sh` regenerates the spec at build time from an inline heredoc
- AppleScript (`osascript`) is used for native file/folder pickers — requires macOS
- The build bundles p7zip from Homebrew's Cellar into the .app; if not found, users must install it separately
- Output always lands on the source file's directory by default, or a user-specified directory
- Compression timeout is 600 seconds (10 minutes)
